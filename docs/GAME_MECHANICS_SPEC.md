# 🛡️ RetroTank 1985 — Game Mechanics & Defense Architecture Spec

เอกสารข้อกำหนดเชิงเทคนิคสำหรับระบบ **ความเร็วเกม (Game Pace)**, **ระดับความยากสำหรับเด็ก (Kid-Friendly Difficulty)** และ **ระบบการป้องกัน 2 ชั้น (Dual-Layer Defense System)** ใน RetroTank1985

| **Player Tank Speed** | `1.00` px/frame (~60 px/s) | `1.25` px/frame (~75 px/s) | `1.40` px/frame (~84 px/s) |

## 2. 🔄 Stage Transition & Carry-Over Rules (กฎการส่งต่อค่าเมื่อผ่านด่าน)

เมื่อผู้เล่นเคลียร์ศัตรูหมดด่านและผ่านการนับคะแนน (Score Tally) เพื่อไปด่านถัดไป:

| ค่าสถานะ (Player State) | เมื่อผ่านด่าน (Next Stage) | เมื่อกด Restart / Game Over |
| :--- | :--- | :--- |
| **❤️ Lives (ตัวเกิด)** | **คงอยู่ ไม่โดนรีเซ็ต (Carry Over)** เช่น เหลือ 4 ตัว ก็นำ 4 ตัวไปเล่นต่อ | รีเซ็ตกลับเป็นค่าเริ่มต้นตาม Preset |
| **⭐ StarPower (ดาวอัปเกรด)** | **คงอยู่ (Carry Over)** ยังคงยิงเร็ว/ทะลุเหล็กต่อเนื่อง | รีเซ็ตเป็น 0 |
| **🏆 Score (คะแนน)** | **นับสะสมต่อเนื่องไปเรื่อยๆ** | รีเซ็ตเป็น 0 (บันทึก High Score) |
| **🛡️ Armor HP (เกราะ)** | **ฟื้นฟูเต็มตาม Preset ให้ใหม่ทุกด่าน** เพื่อเริ่มลุยด่านใหม่อย่างมั่นใจ | รีเซ็ตเต็มตาม Preset |

## 2. 🛡️ Dual-Layer Defense & Armor Ring System (ระบบป้องกัน 2 ชั้น)

ระบบความอึดและการป้องกันของผู้เล่นถูกแบ่งออกเป็น **2 เลเยอร์ชัดเจน**:

```text
               +-------------------------------------------------------+
               |        🎯 ENEMY BULLET INCOMING (กระสุนศัตรูยิงมา)       |
               +---------------------------+---------------------------+
                                           |
                                           v
    =============================================================================
    [LAYER 1] TEMPORARY INVULNERABILITY SHIELD (ชิลด์อมตะ 100% ชั่วคราว)
    - ✨ Classic NES Shield (0x28/0x2C) หรือ 🔮 Cyber Force Field (เส้นประสีฟ้า)
    =============================================================================
               |                                           |
     (มีชิลด์คุ้มกัน)                             (ไม่มีชิลด์ / ชิลด์หมดเวลา)
               |                                           |
               v                                           v
    +----------------------+             ========================================
    |  🛡️ ABSORB HIT       |             [LAYER 2] PERMANENT ARMOR HP RINGS
    |  - กระสุนสลายตัว       |             (เกราะพลังชีวิตถาวร)
    |  - ไม่เสีย HP / Lives |             ========================================
    +----------------------+                               |
                                                           v
                                            +------------------------------+
                                            | ตรวจสอบ HP ปัจจุบันของผู้เล่น |
                                            +--------------+---------------+
                                                           |
                                 +-------------------------+-------------------------+
                                 |                                                   |
                         [ HP > 1 มีเกราะ ]                                  [ HP = 1 ตัวเปล่า ]
                                 |                                                   |
                                 v                                                   v
                  +------------------------------+                    +------------------------------+
                  |  ⚡ REDUCE ARMOR (-1 HP)      |                    |  💀 TANK DESTROYED           |
                  |  - วงแหวนลดสี 5->3->2->หาย    |                    |  - ระเบิด เสีย 1 Life        |
                  |  - เสียงเอฟเฟกต์ HitArmor     |                    |  - เสียงเอฟเฟกต์ Explosion   |
                  |  - อมตะชั่วขณะ 1s (i-Frames)  |                    |  - เกิดใหม่เติม HP เต็ม      |
                  +------------------------------+                    +------------------------------+
```

### การลดทอนสถานะเกราะ (Armor HP Degradation Flow):

```text
  [ 5 HP / 4 HP ]               [ 3 HP ]                 [ 2 HP ]                 [ 1 HP ]              [ 0 HP ]
+-------------------+     +-------------------+    +-------------------+    +-------------------+    +------------+
| 👶 MEGA ARMOR      | --> | 🛡️ HIGH ARMOR      | -> | ⚡ MEDIUM ARMOR    | -> | 💥 NO ARMOR        | -> | 💀 DIE     |
| วงแหวนฟ้า 6 แฉก    |     | วงแหวนเขียว 4 แฉก  |    | วงแหวนทอง 3 แฉก   |    | ตัวเปล่าดั้งเดิม   |    | เสีย 1 ตัว |
+-------------------+     +-------------------+    +-------------------+    +-------------------+    +------------+
```

### รายละเอียด 6 รูปแบบการแสดงผล (Visual Specifications):

1. **💥 1 HP (NO ARMOR)**:
   - ตัวเปล่าตามต้นฉบับ ไม่มีวงแหวนใดๆ ล้อมรอบ โดนยิง 1 นัดระเบิดทันที
2. **⚡ 2 HP (1x SHIELD RING)**:
   - วงแหวนสีเหลืองทอง (`#f59e0b`) 3 แฉก ป้องกันได้ 1 นัด (เมื่อโดนยิง เกราะแตกกลายเป็น 1 HP ตัวเปล่า)
3. **🛡️ 3 HP (2x SHIELD RING)**:
   - วงแหวนสีเขียวมรกต (`#10b981`) 4 แฉก ป้องกันได้ 2 นัด (ลดทอน $3 \rightarrow 2 \rightarrow 1$)
4. **👶 5 HP (KIDS SAFE / MEGA ARMOR)**:
   - วงแหวนสีฟ้านีออน (`#06b6d4`) 6 แฉก ทนได้ 4 นัด สำหรับเด็กเล่นสบายๆ
5. **✨ CLASSIC NES SHIELD**:
   - ลายชิลด์กะพริบดั้งเดิมตอนเกิดใหม่ของ Famicom (Metasprite `0x28` / `0x2C`)
6. **🔮 FORCE FIELD DUAL (FULL DEFENSE)**:
   - การทำงานร่วมกันระหว่าง **เกราะ HP ด้านใน** (เขียว/ฟ้า) + **ม่านบาเรียเส้นประสีฟ้าเรืองแสงรอบนอก** (เมื่อเก็บไอเทมหมวกกันน็อก ⛑️ หรือเพิ่งเกิดใหม่)
   - ม่านบาเรียชั้นนอกจะรับดาเมจแทนจนกว่าจะหมดเวลา จากนั้นจึงสลายตัวเหลือเกราะวงแหวนด้านใน

## 4. 📐 Precision Hitbox & Collision Physics (การคำนวณการชนที่แม่นยำ)

เพื่อแก้ไขปัญหาตัวรถถังโดนยิงทั้งๆ ที่ไม่ได้อยู่ในแนวกระสุน (Adjacent Lane Collision Bug):

```text
                  [ Tank Physical Body (16x16 px) ]
               +-------------------------------------+
               | (X, Y)                              |
               |     +-------------------------+     |
               |     |   🎯 INNER HITBOX       |     |
               |     |   Radius = 8.0 px       |     |
               |     |   Center = (X+8, Y+8)   |     |
               |     |                         |     |
               |     +-------------------------+     |
               |                                     |
               +-------------------------------------+

Bullet: 4x4 px, Center = (b.X + 2.0, b.Y + 2.0)

Center-to-Center AABB Formula:
  dx = MathF.Abs((b.X + 2.0f) - (tank.X + 8.0f))
  dy = MathF.Abs((b.Y + 2.0f) - (tank.Y + 8.0f))
  Collision Hit = (dx <= 8.0f) && (dy <= 8.0f)
```

- **ประโยชน์**: กระสุนที่วิ่งในเลนหรือช่องทางเดินติดกันจะไม่เฉี่ยวโดนรถถังอีกต่อไป ต้องเป็นแนวกระสุนที่พุ่งเข้ากระทบตัวถังโดยตรงเท่านั้น
